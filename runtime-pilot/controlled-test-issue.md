This issue is a dedicated, public test receiver for the Action-Effect runtime
interoperability pilot. Comments contain synthetic text only. The pilot compares
MCP and SDK entry points with a conditional effect description and a complete
structured-adapter baseline, both using actual OPA authorization.

The scheduled run permits at most 12 new comments. Other cases must withhold
execution, or reconcile an already sent comment without posting it again. This
is not a vulnerability report or a claim of independent external validation.

Run results, source identities, limitations and read-only verification instructions
will be linked from this repository. We keep the comments as observable evidence;
their current contents do not prove all internal GitHub consequences or execution
provenance. GitHub notifications and webhooks are explicitly outside our complete
observation coverage.
