# Public Benchmark Scope

Editorial date: 18 October 2026, America/Toronto. Run identities use UTC.

This release selects the evaluation proposal, case-index schema and design
inventory, collaboration boundaries, the 80-case source-frozen corpus and its
generator, 22 post-review regression cases, process runner and scorer tests.
It also includes fresh run reports for the selected public source revision,
reproduction metadata and contribution/security instructions.

The original local drafting archive, earlier internal reports and review logs
remain preserved outside this release. No old result is relabeled as a run of
the public source snapshot. No third-party source archive, Studio application,
private customer information, secret or active protected research case is
published. There is no paid service, cloud deployment or model invocation.

The exact selected files are the Git tree of the chosen Bench commit.
`spec-lock.json` pins the companion Spec commit; individual source hashes and
raw consumer response bytes appear in each new JSON report. Runtime versions
and diagnostic timing are recorded, not assumed identical across machines.

## Independence

This is an AI-assisted, same-project development exercise. The initial case
author used frozen public contract files rather than either candidate's source
or output. The consumer authors initially worked separately from the common
contract. Internal review and later regression construction are disclosed.
This separation does not establish independence from model training data or an
external laboratory. The two published repositories do not constitute separate
institutions or independent benchmark governance.

No protected confirmatory cohort is included. A fresh external cohort needs
actual case custody, rights, independent labels, frozen scoring and a declared
exposure process before any confirmatory run. Existing public cases cannot be
made independent by hashing, renaming or hiding them later.
