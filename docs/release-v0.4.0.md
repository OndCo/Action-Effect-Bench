Bench prerelease `v0.4.0-draft.1`. Editorial date: 19 October 2026,
America/Toronto. This extends evidence, not the core wire version or a standard

## Results

- Six preserved real-model candidates: two eligible reports delivered, four
  task-budget failures still withheld. No new model run or automatic rewrite.
- Official GitHub MCP and Octokit create actual objects on one owned issue.
- Six separately identified fault scenarios, twenty fresh workers total.
- Five native comment calls and five objects; only two are maintainer reports.
- Two current-policy denials make no call. Three lost-confirmation cases recover
  through reads; a pre-send crash remains unknown. Eight duplicate probes make
  no additional call.
- The supervisor run takes 52.437 seconds with fresh-worker startup, shadows
  and networking included. Earlier issue creation and setup are separate,
  excluded costs. Unequal tasks and fixed shadow order do not justify a speed
  ranking.
- Offline replay reconstructs 283 records and 78 historical source entries.
  Six anonymous GETs separately match the issue and five exact comment bodies.

The full manuscript retains the protocol semantics, algorithms, invariants,
counterexamples, competent baseline and older failures, and adds native effect
delivery, real failure cuts, whole-process costs and public observation limits.

## Limits

Same-project self-use is not customer production, an independent human study,
or a completed general conformance certification. Single-host occurrence
ownership is not cross-provider exactly-once execution. Current-content recovery
does not authenticate all historical events or observe notification descendants.
The last-local-check/remote-commit revocation race remains explicit. Fault cuts
are deliberately induced, not naturally observed internet outages.

No Studio/Hook modification, new Azure resource, customer or protected research
data, external invitation or formal paper submission is included. Prior release
PDFs, raw data, code identities and failed attempts are preserved, not replaced.
